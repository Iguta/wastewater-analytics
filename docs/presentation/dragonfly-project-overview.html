What we built

A hidden flow meter in data you already log.

1 · Measure

From pump on/off times alone, compute each pump’s capacity. Rain cancels out of the calculation.

2 · Compare

Each pump against its own history, with the sibling pump as a control group.

3 · Warn

Raise Watch, then Investigate, only when capacity falls and stays down.

Delivered through an operator UI, a read-only Ignition view, and an MCP server so any AI agent can query it.

Read-only. Never writes to a PLC or SCADA tag.

SCADA-native

We build on top of SCADA, not instead of it.

1 · Stays as it is

Data acquisition

Pumps, PLCs, RTUs and the SCADA historian keep running untouched. We replace nothing.

2 · Added on top

Dragonfly analysis

Reads the pump on/off and wet-well level data SCADA already logs. Read-only.

3 · Shown where operators work

Inside the SCADA screen

An Ignition Perspective view shows station tiles, the safety strip and the attention queue.

No new sensors, no rip-and-replace, no write path. The view only fills read-only memory tags and never writes to a device or OPC tag.

The Ignition view is a read-only add-on built on the same API as the web UI.

Reading the screen

What the numbers mean.

Capacity, in “/h”

How many times this pump could empty the wet well’s working volume in an hour. Higher is stronger.

Capacity change, in %

Today against this pump’s own normal. −18.4% means 18.4% weaker than usual (example value).

Running total of shortfall

Adds up each day a pump runs below normal. One bad day fades out; a lasting drop keeps climbing.

Watch line and Investigate line

Watch at 3, Investigate at 6, and Investigate also needs 2 of the last 3 days low.

Run time: observed vs expected

Seconds per run today against what a healthy pump would take at today’s inflow (example: 212 s vs 173 s).

Evidence quality

Sufficient means 20 or more complete pump cycles that day. Otherwise it says Partial or Not enough data.

Example values come from our design mock. Rain does not change capacity, so a storm alone does not raise a flag.

Honest by design

It says plainly when it does not know.

Read-only

No write path to any control system. Safety alarms are never hidden.

Evidence, not guesses

Every alert shows raw timestamps, data quality and what is missing.

No failure predictions

It flags a pump to inspect. It never gives a failure date or a probability.

Simulations are labeled

Indiana incidents are record-anchored what-ifs, not real station data.
